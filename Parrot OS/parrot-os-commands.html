Privilege & Session Management
01 sudo SuperUser DO — temporary root execution
sudo [command]

sudo ("SuperUser DO") lets you run a single command with root (administrator) privileges without fully switching to the root account. It checks if your user is in the sudoers file, asks for your password, executes the command as root, then returns you to your normal session.

examples
sudo apt update             # Update package list as root
sudo apt upgrade            # Upgrade all packages
sudo nano /etc/hosts        # Edit a protected system file
sudo reboot                 # Restart the system
sudo -l                      # List commands you're allowed to run with sudo
sudo -u www-data command    # Run command as a different user
ℹ You remain as your normal user — only that one command runs as root. Your sudo session is cached for ~15 minutes.
02 su Switch User — full identity change
su [username]

su ("Switch User") fully switches your terminal session to another user account. If no username is given, it switches to root. Unlike sudo, it asks for the target user's password and changes your entire session identity until you type exit.

examples
su                   # Switch to root (asks for ROOT's password)
su john              # Switch to user 'john' (asks for john's password)
su -                  # Switch to root AND load root's full environment
su - john            # Switch to john with their full login environment
su -c "command" user # Run a single command as another user
⚡ The difference between su and su - matters: without - you keep your current environment variables; with - you get a full login shell as the target user.
03 sudo su Become root using YOUR password
sudo su

Combines sudo and su — uses your sudo privileges to switch to root, using your own password rather than root's password. This is the most common way to get a persistent root shell in Parrot OS when root has no direct password set.

examples
sudo su             # Become root using your password
sudo su -           # Become root with root's full login environment
sudo su - john     # Become john using your sudo privileges

File & Text Operations
04 cat Concatenate — read and display files
cat [options] [file(s)]

cat ("Concatenate") reads file contents and writes them to standard output (the terminal). It can display single files, combine multiple files, create files from input, and append content. One of the most frequently used Linux commands.

examples
cat file.txt                   # Display file contents
cat file1.txt file2.txt         # Display both files together
cat file1.txt > file2.txt       # Copy file1 into file2 (overwrites)
cat file1.txt >> file2.txt      # Append file1 contents to file2
cat -n file.txt                 # Display with line numbers
cat -A file.txt                 # Show hidden characters (tabs, line endings)
cat > newfile.txt               # Create new file from keyboard input (Ctrl+D to save)
05 echo Print text and variables to terminal
echo [options] [string/variable]

echo outputs text, variables, or command results to the terminal. Widely used in scripts for messages, writing to files, and inspecting environment variables.

examples
echo "Hello World"              # Print text
echo $USER                       # Print current username variable
echo $PATH                       # Print the PATH variable
echo $HOME                       # Print home directory path
echo "text" > file.txt           # Write text to file (overwrites)
echo "text" >> file.txt          # Append text to file
echo -e "Line1\nLine2"           # -e enables \n (newline) escape sequences
echo -n "No newline"             # -n suppresses trailing newline
06 history Browse and reuse past commands
history [number]

Displays a numbered list of previously executed commands stored in ~/.bash_history. You can re-execute any command by its number, search through history, or clear it entirely.

examples
history                      # Show all command history
history 20                   # Show last 20 commands
!150                         # Re-run command number 150
!!                           # Re-run the very last command
!sudo                        # Re-run the last command that started with 'sudo'
history -c                   # Clear all history from memory
history | grep ssh          # Search history for 'ssh' commands
Ctrl+R                       # Reverse interactive search through history
07 clear Clean the terminal screen
clear

Clears all visible text from the terminal screen. History is NOT deleted — it just scrolls out of view. The terminal buffer and command history remain intact.

examples
clear           # Clear the terminal screen
Ctrl+L          # Keyboard shortcut — identical effect
reset           # Full terminal reset (fixes broken display/encoding)
Directory & File Management
08 mkdir Make Directory — create folders
mkdir [options] directory_name

mkdir ("Make Directory") creates new folders. Can create single directories, multiple at once, or deeply nested paths with a single command using the -p flag.

examples
mkdir myfolder                          # Create a single folder
mkdir folder1 folder2 folder3           # Create multiple folders at once
mkdir -p projects/web/html             # Create nested folders (parents too)
mkdir -m 755 securefolder             # Create folder with specific permissions
mkdir -v newfolder                     # Verbose: print what was created
09 rmdir Remove empty directories only
rmdir [options] directory_name

rmdir ("Remove Directory") deletes empty folders only. It will fail if the directory contains any files or subdirectories. For non-empty directories, use rm -rf.

examples
rmdir myfolder           # Remove empty folder
rmdir -p a/b/c           # Remove nested empty directories recursively
rmdir -v myfolder        # Verbose output of what was removed
⚡ rmdir only works on empty directories. Use rm -rf foldername to delete folders with content.
10 touch Create empty files or update timestamps
touch [options] filename

touch creates a new empty file if it doesn't exist, or updates the last-accessed and last-modified timestamps of an existing file without changing its contents.

examples
touch newfile.txt                      # Create an empty file
touch file1.txt file2.txt file3.txt    # Create multiple files at once
touch -t 202301011200 file.txt        # Set specific timestamp (YYYYMMDDhhmm)
touch -a file.txt                     # Update only access time
touch -m file.txt                     # Update only modification time
11 rm -rf Force delete files and directories recursively
rm [options] [file/directory]

rm -rf removes files and directories. The -r flag means recursive (including all contents), and -f means force (no confirmation prompts, ignores errors). Together they permanently delete anything you point them at.

examples
rm file.txt              # Delete a single file
rm file1.txt file2.txt   # Delete multiple files
rm -r myfolder/          # Delete folder and all contents (asks confirmation)
rm -f file.txt           # Force delete, no prompts
rm -rf myfolder/         # Force delete folder and everything inside silently
rm -i file.txt           # Interactive: ask before each deletion (safer)
No Recycle Bin

Files deleted with rm are permanently gone. There is no Trash folder. There is no undo. Always double-check your path before running rm -rf.

12 exit End current session or shell
exit [status_code]

exit terminates the current shell session. If you used su or sudo su to switch users, exit returns you to the previous user. In a script, the exit code signals success (0) or failure (non-zero) to the calling process.

examples
exit           # Exit current terminal/session
exit 0         # Exit with status 0 (success)
exit 1         # Exit with status 1 (general error)
exit 127       # Exit code 127 = command not found
Ctrl+D         # Keyboard shortcut that sends EOF, same as exit
Navigation
13 & 14 cd  /  cd .. Change Directory — navigate the filesystem
cd [directory]

cd ("Change Directory") navigates through the Linux filesystem. cd .. specifically moves one level up to the parent directory. Understanding absolute vs relative paths is key to using cd effectively.

navigation examples
cd /home/user/Desktop    # Go to an absolute path (from root /)
cd Documents             # Go to a relative path (from current location)
cd ~                     # Go to your home directory
cd                       # Same as cd ~ (home directory)
cd -                     # Go back to the previous directory
cd ..                    # Go up ONE level (to parent directory)
cd ../..                 # Go up TWO levels
cd ../../etc             # Go up two levels then into 'etc'
cd /                     # Go to the root of the filesystem
ShortcutMeaning
~Your home directory (/home/username)
.Current directory
..Parent directory (one level up)
-Previous directory (toggle)
/Root of the entire filesystem
15 & 16 ls  /  pwd List contents / Print working directory
ls [options] [path]    |    pwd

ls ("List") shows the files and directories in a location. pwd ("Print Working Directory") shows you exactly where you currently are in the filesystem as a full absolute path.

ls examples
ls                   # List current directory (visible files only)
ls /etc              # List contents of /etc
ls -l                # Long format: permissions, owner, size, date
ls -a                # Show ALL files including hidden (dot files)
ls -la               # Long format + hidden files (most useful combo)
ls -al               # Identical to ls -la (flag order doesn't matter)
ls -lh               # Human-readable file sizes (KB, MB, GB)
ls -lt               # Sort by modification time (newest first)
ls -lS               # Sort by file size (largest first)
ls *.txt             # List only .txt files (wildcard)

# pwd example
pwd                  # Output: /home/parrot/Documents
ℹ ls -la output decoded: The first column like -rwxr-xr-x shows: file type (-=file, d=dir, l=link), then owner/group/other permissions (r=read, w=write, x=execute).
ls -la output columns
# Permissions  Links  Owner   Group   Size    Date         Name
  -rwxr-xr-x   1      parrot  parrot  4096    Jan 5 12:00  script.sh
  drwxr-xr-x   2      parrot  parrot  4096    Jan 5 11:00  .hidden_folder
  lrwxrwxrwx   1      root    root    7       Jan 1 00:00  link -> target
⚠ Danger Zone
⚠ rm -rf /* SYSTEM DESTROYER — educational awareness only
CRITICAL DANGER — NEVER RUN THIS COMMAND

This command recursively and forcefully deletes EVERYTHING from the root / directory — your entire operating system, all files, all configurations, all user data. The system will crash mid-deletion and become completely unbootable. There is no undo. There is no recovery without a full backup.

This command is documented here purely for educational awareness — so you recognize it, understand why it's catastrophic, and never run it. It's also used so you can recognize if someone is trying to trick you into running it.

breakdown (DO NOT RUN)
rm           # The remove command
-r           # Recursive: deletes all folders and subfolders
-f           # Force: no warnings, no confirmation prompts
/*           # EVERYTHING inside / (root) = the entire system

# Result: complete operating system destruction
⚡ Modern Linux has a safeguard: you need --no-preserve-root flag to run this. But some older systems or misconfigured environments may not. Never run it regardless.
System & User Information
19 whoami Display the current active username
whoami

Prints the username of the currently effective user. After sudo su or su, this confirms whether you're actually running as root or as your original user.

examples
whoami             # Output: parrot (or root if you're root)
id                 # More detail: uid, gid, and all groups
id john            # Show id info for another user
who                # Show all users currently logged in
w                  # Extended: who's logged in + what they're doing
User Management
20 & 21 useradd  /  adduser Create new user accounts
useradd [options] username    |    adduser username

useradd is a low-level command that creates users without a home directory or password by default — requires manual setup. adduser is a friendlier, interactive wizard that sets everything up automatically. Use adduser for normal use; useradd for scripting.

useradd (low-level)
sudo useradd john                       # Create user (no home dir, no password!)
sudo useradd -m john                   # Create user WITH home directory
sudo useradd -m -s /bin/bash john    # With home dir and bash shell
sudo useradd -m -G sudo john          # Create user and add to sudo group
sudo passwd john                        # Set password separately (required!)
adduser (interactive — recommended)
sudo adduser john    # Interactive wizard: sets up home dir, password, full name, etc.

# You'll be prompted for:
# New password / Confirm password
# Full Name, Room Number, Work Phone, Home Phone (all optional)
# Confirmation: Is the information correct? [Y/n]
✓ Recommended: Use adduser for manual user creation. Use useradd in shell scripts where you need full control.
22 passwd Change user passwords
passwd [username]

The passwd command changes user account passwords. Running it without arguments changes your own password. With a username (and root/sudo), it changes that user's password.

examples
passwd                  # Change YOUR OWN password
sudo passwd john        # Change john's password (as root)
sudo passwd root        # Set/change the root password
sudo passwd -l john    # Lock john's account (disable login)
sudo passwd -u john    # Unlock john's account
sudo passwd -e john    # Expire password: force change at next login
sudo passwd -S john    # Show password status for john
23 userdel / deluser Remove user accounts from the system
userdel [options] username    |    deluser username

Removes user accounts. By default, the home directory is preserved. Add the -r flag to also delete the home directory and mail spool.

examples
sudo userdel john                   # Delete user, KEEP home directory
sudo userdel -r john               # Delete user AND remove home dir + mail
sudo deluser john                   # Friendlier version (like adduser)
sudo deluser --remove-home john    # Friendly version with home dir removal
sudo deluser john sudo             # Remove john FROM the sudo group (not delete user)
⚡ Always ensure the user is logged out before deleting. Check with who command first.
24 usermod -aG sudo Grant administrator (sudo) privileges
sudo usermod -aG sudo username

Making a user an admin means adding them to the sudo group. Once in this group, they can run commands with sudo. The -a flag means append (don't remove from other groups), -G specifies the group.

methods
# Method 1 — usermod (most common)
sudo usermod -aG sudo john

# Method 2 — gpasswd
sudo gpasswd -a john sudo

# Method 3 — Add to multiple groups at once
sudo usermod -aG sudo,adm,dialout john

# Verify it worked
groups john          # Should show 'sudo' in the output
id john              # Full details including group memberships
ℹ The user must log out and log back in for group changes to take effect. The new shell session will load the updated group membership.
System Services
25 systemctl Manage systemd services — start, stop, enable
systemctl [action] [service-name]

Parrot OS uses systemd as its init system. systemctl is the primary tool to manage system services — start/stop them, check their status, and control whether they auto-start at boot.

basic service control
sudo systemctl start   apache2       # Start a service
sudo systemctl stop    apache2       # Stop a service
sudo systemctl restart apache2       # Stop then start again (full restart)
sudo systemctl reload  apache2       # Reload config without stopping
sudo systemctl status  apache2       # Check if running + last log lines
boot persistence
sudo systemctl enable  apache2       # Auto-start service at every boot
sudo systemctl disable apache2       # Don't auto-start at boot
sudo systemctl enable --now apache2 # Enable AND start immediately
systemctl is-enabled   apache2       # Check if enabled for boot
systemctl is-active    apache2       # Check if currently running
listing & exploring
systemctl list-units --type=service         # All active services
systemctl list-units --type=service --all   # All services (active + inactive)
systemctl list-unit-files                   # All installed service files
journalctl -u apache2                       # View logs for a specific service
journalctl -u apache2 -f                   # Follow live logs
ServiceCommandPurpose
apache2sudo systemctl start apache2Web server
mysqlsudo systemctl start mysqlMySQL database

Network Reconnaissance
26 nmap Network Mapper — port scanning & host discovery
nmap [options] [target]

nmap (Network Mapper) is the industry-standard tool for network exploration and security auditing. It discovers hosts, open ports, running services, service versions, operating systems, and known vulnerabilities. It's one of the most essential tools in the Parrot OS security toolkit.

basic scanning
nmap 192.168.1.1            # Basic scan of a single IP
nmap 192.168.1.1-254        # Scan a range of IPs
nmap 192.168.1.0/24         # Scan an entire subnet (256 hosts)
nmap scanme.nmap.org        # Scan by domain name
nmap 10.0.0.1 10.0.0.2     # Scan multiple specific targets
port scanning
nmap -p 80 192.168.1.1             # Scan a specific port
nmap -p 80,443,22 192.168.1.1     # Scan multiple specific ports
nmap -p 1-1000 192.168.1.1        # Scan a port range
nmap -p- 192.168.1.1              # Scan ALL 65535 ports (thorough)
nmap --top-ports 100 192.168.1.1 # Scan the 100 most common ports
scan types
nmap -sS 192.168.1.1     # SYN Stealth Scan (default, fast, less detectable)
nmap -sT 192.168.1.1     # TCP Connect Scan (slower, no root needed)
nmap -sU 192.168.1.1     # UDP Scan (slow but finds UDP services)
nmap -sn 192.168.1.0/24 # Ping Scan: just check which hosts are alive
nmap -sA 192.168.1.1     # ACK Scan: map firewall rules
detection & fingerprinting
nmap -sV 192.168.1.1          # Detect service/version on open ports
nmap -O  192.168.1.1          # Detect operating system (requires root)
nmap -A  192.168.1.1          # Aggressive: OS + version + scripts + traceroute
nmap -sC 192.168.1.1         # Run default NSE scripts
nmap -sC -sV 192.168.1.1    # Default scripts + version detection (common combo)
speed control (-T0 slowest → -T5 fastest)
nmap -T0 192.168.1.1    # Paranoid (very slow, evasive, IDS bypass)
nmap -T3 192.168.1.1    # Normal (default timing)
nmap -T4 192.168.1.1    # Aggressive (fast, good for LAN)
nmap -T5 192.168.1.1    # Insane (fastest — may miss results)
NSE scripts (nmap scripting engine)
nmap --script vuln 192.168.1.1           # Scan for known CVE vulnerabilities
nmap --script http-title 192.168.1.1      # Get web page titles
nmap --script banner 192.168.1.1          # Grab service banners
nmap --script ftp-anon 192.168.1.1        # Check for anonymous FTP login
nmap --script ssh-brute 192.168.1.1       # SSH brute force (authorized use only)
saving output
nmap -oN output.txt 192.168.1.1     # Save in normal text format
nmap -oX output.xml 192.168.1.1     # Save in XML (for tools like Metasploit)
nmap -oG output.gnmap 192.168.1.1   # Save in grepable format
nmap -oA output 192.168.1.1         # Save in ALL three formats at once
full recon example
sudo nmap -A -T4 -p- -oN full_scan.txt 192.168.1.1
# -A     = OS detection + version + default scripts + traceroute
# -T4    = Aggressive timing (fast)
# -p-    = Scan ALL 65535 ports
# -oN    = Save results to full_scan.txt
Legal Warning

Only use nmap on networks and systems you own or have explicit written permission to test. Unauthorized network scanning is illegal under computer crime laws in most countries (including the Computer Fraud and Abuse Act in the US). Always scan responsibly.
